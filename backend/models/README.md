# Models

This folder stores the trained AI model weights required by the traffic violation detection system.

## Supported Models
- `best.pt` – Trained YOLOv8 model for traffic violation detection.
- `yolov8n.pt` – Pre-trained YOLOv8 Nano model.

> **Note:** Model weight files are not included in this repository because of their large size. Download or train the required models and place them in this folder before running the project.
