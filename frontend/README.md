# Frontend

## Overview

This folder contains the React.js frontend of the Spatio-Temporal Traffic Violation Detection System. It provides an interactive dashboard for monitoring, visualizing, and managing traffic violations detected by the backend AI modules.

## Features

- Real-time violation dashboard
- Traffic violation statistics
- Interactive analytics charts
- Evidence image display
- Processed video visualization
- GNSS-based location mapping
- E-challan generation
- Responsive user interface

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Chart.js
- Leaflet (Map Visualization)
- Flask REST API Integration
